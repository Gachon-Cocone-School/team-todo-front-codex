# Team Todo

팀 TODO 백엔드에 연결해 할 일을 만들고 관리하는 Next.js 웹 앱입니다. 로그인 없이 사용할 수 있으며, 설정 화면에서 **Productivity**와 **Warm** 테마를 바꿀 수 있습니다.

## 시작하기

### 준비물

- Node.js 24 이상
- npm
- 실행 중인 Team Todo 백엔드

### 설치 및 실행

저장소 루트에서 다음 명령을 실행합니다.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

`.env.local`의 `API_BASE_URL`은 백엔드 주소를 지정합니다. 기본값은 `http://127.0.0.1:8000`입니다. 백엔드가 다른 주소에서 실행된다면 이 값을 수정한 뒤 개발 서버를 다시 시작합니다.

브라우저에서 [http://127.0.0.1:3000](http://127.0.0.1:3000)을 엽니다. 앱은 TODO 목록으로 시작합니다.

## 사용법

### TODO 목록

- **새 할 일**을 눌러 제목을 입력하고 TODO를 만듭니다. 설명, 담당자, 마감일, 우선순위, 상태, 태그도 함께 설정할 수 있습니다.
- 상태, 우선순위, 담당자, 마감일 범위, 태그로 목록을 필터링할 수 있습니다. **필터 적용**을 눌러 조건을 적용하고 **초기화**를 눌러 전체 목록으로 돌아갑니다.
- 목록은 페이지마다 20개씩 표시됩니다. 아래의 이전/다음 버튼으로 페이지를 이동합니다.
- TODO 항목을 선택하면 상세 화면으로 이동합니다.

### TODO 상세

상세 화면에서 제목, 설명, 담당자, 마감일, 우선순위, 상태, 태그와 생성·수정 시각을 확인할 수 있습니다. **수정**을 눌러 내용을 바꾸고 저장하거나 **삭제**를 눌러 항목을 삭제합니다. 삭제는 확인 대화상자를 거치며, 삭제된 TODO는 복구할 수 없습니다.

### 테마 설정

사이드 메뉴의 **설정**에서 Productivity 또는 Warm 테마를 선택합니다. 선택 즉시 앱 전체에 적용되며 이 브라우저에 저장되어 다음 방문에도 유지됩니다.

## 주요 화면

| 경로          | 화면                               |
| ------------- | ---------------------------------- |
| `/`           | TODO 목록, 필터, 페이지 이동, 생성 |
| `/todos/{id}` | TODO 상세, 수정, 삭제              |
| `/settings`   | 테마 선택                          |

백엔드 요청은 Next.js 프록시를 통해 전달합니다. 브라우저는 `/api/backend/todos`를 호출하며, 서버가 `API_BASE_URL`에 지정된 백엔드의 `/api/v1/todos`로 요청을 전달합니다.

## 확인 및 테스트

```sh
npm test       # Vitest 단위·컴포넌트 테스트
npm run check  # lint, format, typecheck, test, production build
```

수동 테스트가 필요하면 [docs/TEST_CASE.md](docs/TEST_CASE.md)의 시나리오를 사용합니다. Playwright E2E 테스트는 포함하지 않습니다.
